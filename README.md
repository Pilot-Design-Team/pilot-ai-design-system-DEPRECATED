# design.pilot.com

This repository powers **design.pilot.com** — Pilot's design system hub.

---

## 📂 Repository Structure

### Marketing AI Design System → [`/marketing`](./marketing)

If you're looking for the **Pilot Marketing AI Design System**, it lives in the [`marketing/`](./marketing) folder.

That folder contains:
- **`index.html`** — The interactive design system visualizer (served at `design.pilot.com/marketing`)
- **`pilot-design-system.md`** — The full design system markdown reference (source of truth for AI agents)
- **`pilot-design-system-md-viewer.html`** — A rendered viewer for the markdown file
- **`fonts/`** — Euclid Circular B web fonts
- **`icons/`** — Pilot icon library (Key Color variants)
- **`images/`** — Marketing imagery and assets
- **`logos/`** — Pilot logo assets in multiple formats
- **`slides-export/`** — Exported slide decks

### AI Agents

**To use this design system in your project**, clone this repo and point your agent to:

```
marketing/pilot-design-system.md
```

That file is the single source of truth for colors, typography, spacing, components, and brand guidelines.
